## Conseils pour les photos

- **Format** : JPG ou WebP
- **Résolution** : 1200px de large minimum, 2000px idéalement
- **Orientation** : paysage pour les projets (ratio 4:3), portrait pour les personnes (ratio 3:4)
- **Lumière** : privilégiez la lumière naturelle ou un bon éclairage d'intérieur
- **Cadrage** : centrez le sujet, montrez les finitions et détails

## Ajouter un nouveau projet

1. Ajoutez votre image ici : `projet-7.jpg` (ou le nom de votre choix)
2. Ouvrez le fichier `/lib/projects.js`
3. Copiez un objet existant et remplissez les champs
4. Changez `image: '/images/projet-7.jpg'`
5. Enregistrez — le projet apparaît automatiquement sur le site
